# Journal of Imaging (MDPI) submission — Overleaf package

Ported from the WACV two-column draft in `../overleaf_WACV/`, which is kept intact as the
record of the conference version. **This directory is now the canonical manuscript.**

Upload the whole folder to Overleaf (New Project → Upload Project → zip it first) and set
the compiler to **pdfLaTeX** (Menu → Settings).

```
main.tex              class options, title, authors, abstract, keywords, back matter
main.bib              21 references, all cited
Definitions/          MDPI class, bst files and logos, unmodified as shipped
sec/1_intro.tex       Introduction + contributions
sec/2_related.tex     Related Work
sec/3_methods.tex     Materials and Methods (corpus, pipeline, criterion, decomposition, protocol)
sec/4_results.tex     Results (9 subsections)
sec/5_discussion.tex  Discussion, including Limitations
sec/6_conclusions.tex Conclusions
sec/7_appendix.tex    Appendix A — complete ablation catalogue
figures/              4 analysis figures (PDF, vector) + pipeline, qualitative, evidence, dataset grid
```

## What changed in the port

| | WACV | MDPI |
|---|---|---|
| Layout | two column | single column; every `figure*`/`table*` became `figure`/`table` with `[H]` |
| Wide floats | `\linewidth` | `adjustwidth{-\extralength}` + `\fulllength` |
| Sections | Intro / Related / Dataset / Method / Experiments / Limitation / Conclusion | Intro / Related / **Materials and Methods** / **Results** / **Discussion** / Conclusions |
| Appendix | 4 tables + 4 empty stub subsections | folded into the main text; only the ablation catalogue remains as Appendix A |
| Abstract | 290 words, free form | 200 words, MDPI structured style |
| Related Work | `\paragraph{}` | `\subsection{}` |

Two content changes were made during the port, both corrections:

1. **`\S`4.6 "What the Confidence Condition Buys" is new.** It reports the sensitivity of
   the count to the confirmation rule's confidence threshold, from
   `src/eval/conf_sensitivity.py` → `results/counting/conf_sensitivity{,_frozen}.csv`.
2. **"the detector never saw" → "the detector never trained on"** in four captions. Four
   of the 13 held-out videos are the detector's *validation* split: no gradient was
   computed on them, but they influenced checkpoint selection, so "never saw" was not
   accurate. `\S`3.7 now states this explicitly. The dataset section's claim that the
   protocol is worth "33 points" was also wrong and is now 23 (89.0 − 66.3).

## Before you submit

1. **Authors** — `main.tex` has one author and a placeholder ORCID. Complete the list,
   affiliations and corresponding-author email.
2. **Back matter** — `\authorcontributions`, `\funding`, `\institutionalreview`,
   `\dataavailability` and `\acknowledgments` all carry `TODO before submission` markers.
   Search the file for `TODO` and clear every one.
3. **Dataset DOI** — the paper claims a release. Get the Zenodo DOI and put it in
   `\dataavailability` and in `\S`3.1, or soften the claim.
4. **Code release** — same; the repo is currently private.

## Numbers

Every figure is generated by `src/viz/paper_figures.py` from the results CSVs; every table
number traces to a section of `docs/RESULTS_LOG.md` with its job ID. If a number changes,
re-run that script rather than editing the PDF.
